# Intelligent Solutions - Enterprise Data Platform

## Project Overview
- **Name**: data-collectors-ltd
- **Goal**: Enterprise-grade machine learning and data analytics landing page.
- **Features**: Modern animated hero section, interactive architecture visualization, responsive design.

## URLs
- **Production**: https://data-collectors-ltd.pages.dev
- **GitHub**: https://github.com/DrakeNamanya/DATACOLLECTORS-LTD

## Tech Stack
- **Framework**: Hono (Edge-first web framework)
- **Styling**: Tailwind CSS
- **Deployment**: Cloudflare Pages
- **Animation**: CSS3 Keyframes

## Data Architecture Visualized
The application includes a visualized data flow based on the enterprise architecture:
1. **Client App**: Web/Mobile entry points
2. **API Layer**: Node/Django gateway
3. **Backend Services**: Auth, Database, Storage, Cache
4. **Data Pipeline**: Kafka/CDC streaming
5. **Spark Cluster**: Machine Learning processing
6. **Warehouse**: Analytics storage
7. **Dashboard**: User insights

## Deployment
This project is automatically deployed to Cloudflare Pages.
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
